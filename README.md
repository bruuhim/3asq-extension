# 3asq.org Seanime Extension

A Seanime Manga Provider extension for [3asq.org](https://www.3asq.org/).

## Features

- Search for manga on 3asq.org.
- View chapter lists.
- Read manga chapters directly in Seanime.

## Installation

To add this extension to your Seanime instance, add the following URL to your extension settings:

`https://raw.githubusercontent.com/Brahim/3asq-seanime-extension/main/src/3asq.json`

## Development

The extension is written in TypeScript and follows the Seanime Manga Provider API.

### Project Structure

- `src/index.ts`: The main provider implementation.
- `src/3asq.json`: The extension manifest.
- `typing/`: TypeScript definition files for Seanime.
